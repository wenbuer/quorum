# 智群 · Quorum —— 业务逻辑（M0 现状整理）

这份文档只描述**现在真的跑起来的东西**：数据长什么样、命令链怎么走、每条命令执行完落到哪里。
末尾单列一节「模型撑不住的地方」，那些是要你拍板或留到 M1 的。

---

## 1. 领域模型

四样东西，都在前端内存里（设置项除外，见 §7）。

### 计划 Plan —— 计划自己拥有"什么时候"和"多大声"

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | `p-1` 递增 |
| `day` | string | **日期键** `YYYY-MM-DD`，不是星期几。这样日历能翻月 |
| `start` / `end` | number | 小数小时，`9.5` = 09:30，`12.07` ≈ 12:04 |
| `title` | string | 标题 |
| `note` | string | 说明；命令链里的「项目 · 动作」也塞在这里 |
| `role` | string | **角色的名字**（不是 id） |
| `level` | `L1` / `L2` / `L3` | 提醒级别，目前只有颜色和标签 |
| `repeat` | `once` / `daily` | 目前只是存着，没有生成实例 |
| `done` | bool | 勾掉即 true |

### 角色 Role —— 只拥有身份和权限

| 字段 | 说明 |
|---|---|
| `id` / `name` | `r-1` / 显示名 |
| `grants` | 6 项权限，见下 |

权限模板（`grantsTemplate()`）固定 6 项：日历读取、计划写入、文件读写、屏幕截图、浏览器控制、执行脚本，
每项带 `on` 开关和一句 scope 文案。**现在只是 UI 状态，没有任何地方真的校验它们。**

### 项目 Project —— 只拥有文件

| 字段 | 说明 |
|---|---|
| `id` / `name` / `note` | `pr-1` / 显示名 / 说明 |
| `paths` | 目录列表；`查看文件夹` 走 Rust 的 `list_dir` 懒加载 |

### 视图与临时状态

| 名字 | 含义 |
|---|---|
| `view.day` | 当前选中的**日期键**（默认今天），日历点一下即改 |
| `ui.drawer` | 角色抽屉：`null` / `{kind:"role", id?}` / `{kind:"role", name?}`（新建时预填名） |
| `ui.projectDraft` | 一次性通道：命令链把参数递给项目表单，表单**读一次就清空** |

## 2. 窗口与面板的骨架

- **三种窗口形态**：贴边药丸 148×44 / 展开清单 320×(34+36n+10) / 面板自适应 40%×55%（夹 760–1120 × 520–800）。
  几何归内核，前端只调 `set_mode`。
- **面板四个域**，各自一条独立的历史栈（后退/前进不跨域）：

| 域 | 根路由 | 可进入的子页 |
|---|---|---|
| 计划 | `planner` | `plan/:id`（单条详情） |
| 角色 | `roles` | 抽屉（覆盖在列表上，不是路由） |
| 项目 | `projects` | `project/:id`、`project-new` |
| 设置 | `settings` | — |

- 切标签会**清空输入框里的一切**（草稿、胶囊、命令链），因为同一个框在四个域里含义不同。

## 3. 命令链（核心）

### 3.1 两种模式

| | 触发条件 | 可用命令 |
|---|---|---|
| **模式一** | 没有选中项目 | `/新建计划` `/查看计划` `/新建角色` `/编辑角色` `/新建项目` `/编辑项目` `/执行角色` |
| **模式二** | 选中了项目（`@` 选过） | `/交给角色` `/添加路径` |

选中项目后**不能再建角色** —— 这是刻意的：项目是硬边界，链上的动作只能作用于这个项目。

### 3.2 每条命令的执行结果

都以「点开备选 → 回车」为动作，★ 表示实测过的结论。

| 命令 | 参数 | 执行结果 |
|---|---|---|
| `/新建计划` | 内容（可空） | 就地弹出草稿条；内容为空则只切到计划域，让你接着打字 ★ |
| `/查看计划` | — | 列出全部计划（按日期、时间排），选中即打开 `plan/:id` ★ |
| `/新建角色` | 名称（可空） | 切到角色域 → 打开新建抽屉，名称已填进去 ★ |
| `/编辑角色` | —（但会把输入框变成 `/编辑角色 `） | 列出**全部角色**，选中即打开该角色的抽屉 ★ |
| `/新建项目` | 名称、路径（都可空） | 切到项目域 → `project-new`，表单里名称和路径**都预填** ★ |
| `/编辑项目` | —（输入框变成 `/编辑项目 `） | 列出全部项目，选中即打开 `project/:id` ★ |
| `/执行角色` | — | 进入"选角色"阶段，列出全部角色，选中变成**角色胶囊** |
| `/交给角色` | — | 与 `/执行角色` **完全一样**（见 §5 的问题 3） |
| `/添加路径` | 路径（可空） | 把这段文字变成**动作胶囊**，不会写进项目的路径列表（见问题 2） |

参数**全都可以跳过**：在参数槽上直接回车 = 用已填的部分执行（`/新建项目` + 空回车 → 打开空白的项目表单）。

### 3.3 参数链的状态机

```
输入 "/"        → 列出所有命令
选中某条命令     → 有参数：进入参数链，输入框前出现蓝色命令胶囊
                 无参数：立刻执行（见上表）
填一个参数 + 回车 → 该参数变成一颗彩色小胶囊（名称=蓝 / 路径=绿 / 第三个=橙）
                   占位符变成下一个参数名
参数填满        → 执行 finish()，把参数交给对应页面
```

**Esc 逐层回退**，一层一层剥，剥完才关面板：

```
备选菜单开着  → 收菜单
有参数胶囊    → 去掉最后一个参数
只剩命令胶囊  → 去掉命令
还有 @/角色胶囊 → 去掉最后一个
全空          → 这一次才关闭面板
```

**退格**：输入框为空时删掉最后一颗胶囊。

### 3.4 `@` 的语义

- 输入 `@` 列出项目，选中后：加一颗**项目胶囊**，并且**只保留项目+角色胶囊，动作胶囊被丢掉**。
- 项目一旦选中，`@` 就**失效**（不列任何东西）——链条里不能再换项目。
- 项目胶囊决定了用哪套命令表（模式一变模式二）。

### 3.5 没有 `/` 也没有 `@` 时：写一条计划

输入框在计划域里的默认职责是"写一条计划"，按回车先出**草稿条**（不会直接建）：

| 解析 | 规则 |
|---|---|
| 时间 | 正则 `(\d{1,2})\s*[:：点]\s*(\d{1,2})?`，只写小时也算（`下午 3 点` → 15:00 不行，只认数字） |
| 每天 | 出现「每天」或「每日」→ `repeat = daily` |
| 标题 | 原文挖掉时间和"每天"之后剩下的；挖空了就退而用「动作 · 项目」，再空就是"新计划" |
| 级别 | **永远 L1** |
| 时长 | **永远 0.5 小时** |
| 归属日期 | 当前选中的那天（`view.day`） |
| 角色 | 角色胶囊，没有就写「编排」 |
| 说明 | `note = 项目 · 动作` |

草稿条上点「创建计划」才真的写入，点「取消」丢掉。

## 4. 胶囊（悬浮窗）的业务

| 形态 | 内容 |
|---|---|
| 贴边药丸 148×44 | 倒计时 + 下一项标题 + 「+N」；没有任何安排时是「待命 / 今天没有安排」 |
| 展开清单 320×(34+36n+10) | 今天的全部计划：勾选框 + 时间 + 标题 + 等级 |

- **勾选 = 标记 `done`**，已完成的计划不会再触发提醒（这是"勾掉就不弹通知"的实现方式）。
- 点某一行 → 打开面板里那条计划的详情。
- 只有标题条能拖 —— 整块可拖的话勾选会跟拖动打架。
- 倒计时：>1 小时显示 `时:分:秒`，最后一小时 `分:秒`；已开始显示「进行中」，时间窗过了没做显示「已错过」。
- 展开/收起由鼠标进出驱动，收起后有 320ms 宽限。

## 5. 模型撑不住的地方（要你拍板）

| # | 问题 | 现在的样子 | 建议 |
|---|---|---|---|
| 1 | **计划不持有 project / role 的 id** | `role` 存名字、`note` 里拼「项目 · 动作」 | 改成 `projectId` + `roleId`；改名不断链，同名不打架 |
| 2 | `/添加路径` **没有真的加路径** | 只是把文字塞进动作胶囊，然后进 note | 要么真的 `project.paths.push()`，要么删掉这条命令 |
| 3 | `/交给角色` 列出**全部**角色 | 与模式一无差别 | 按项目的授权过滤，或者干脆合并成一条命令 |
| 4 | 计划**不能从输入框设级别和时长** | 永远 L1 / 0.5h | 加 `!L2`、`90分钟` 这类后缀，或草稿条上直接改 |
| 5 | 角色默认写「编排」 | 项目链里也是 | 应为"未指派"或者项目默认角色 |
| 6 | `repeat=daily` 只存不生效 | 没有生成实例的机制 | M1 调度器负责展开 |
| 7 | 非计划域里 **回车没反应** | `canSubmit` 只在计划域放行纯文本 | 要么给各域一个默认动作，要么光标里明确提示"这里只认命令" |
| 8 | `done` 只有两态 | 勾掉 = 完成；想"取消/放弃"只能删掉 | 加 `skipped`，完成和放弃分开统计 |
| 9 | 权限开关**没有任何约束力** | 纯 UI | M3 的闸门 |
| 10 | 没有撤销 | 删计划/删项目/删角色都是直接删 | 至少给删除加一步确认 |

## 6. 边角行为（不是业务，但会被误当成 bug）

- **吸附**：松手后才结算 —— 离屏幕边 12px 内停靠，否则留在原地。拖动途中既不磁吸也不因停顿而收起（靠 `GetAsyncKeyState` 判断左键是否还按着）。
- **位置记忆**：自由位置和停靠位置分别记；面板关闭后回到原来的停靠点，而不是面板留下的坐标。
- **失焦即隐**：面板丢焦点 280ms 后收起；二级窗口开着时不算。
- **右键菜单**：贴边药丸/展开清单上右键 → 重启 / 关闭（关闭 = 收起窗口，热键或托盘再唤出）。
- **托盘**：打开面板 / 关闭悬浮胶囊（关掉后这条自己变成「开启悬浮胶囊」）/ 退出。它是**开关**不是单向关闭：关 = 胶囊收起来，开 = 放回原来的停靠点。托盘和设置页是同一个开关，任一处改动都会同步另一处。

## 7. 设置与落盘

写在这个文件里（内核只负责路径，形状归前端）：

```
%APPDATA%\com.wenbuer.quorum\settings.json
{
  "capsule": "#e7f7fa",
  "floatingIcon": true,
  "hotkey": "Alt+Backquote",
  "llm": { "provider": "openai", "baseUrl": "…", "model": "…", "apiKey": "" }
}
```

| 字段 | 含义 |
|---|---|
| `capsule` | 悬浮窗底色（6 个预设 + 自定义取色），只允许浅色，因为胶囊的深色文字不跟着换 |
| `floatingIcon` | 是否显示悬浮胶囊。关掉后胶囊不再出现在桌面，**面板关闭时也不回来**（`restore()` 直接隐藏）；托盘那一项与它是同一个状态 |
| `hotkey` | 全局热键。**启动先读它**，被占用才回落到内置候选链，所以文件里存的可能是"实际生效的那个" |
| `llm` | 服务商 / 接口地址 / 模型 / 密钥；只有"配置 + 测试连接"，还没有角色真的调用 |

- 写盘是**防抖**的，而且**先读后写** —— 否则启动瞬间的默认值会覆盖用户配置。
- 开机自启不在这里：它写的是注册表 `HKCU\...\Run`，状态以注册表为准。
- 大模型目前只有"配置 + 测试连接"，**没有任何角色真的调用它**。

## 8. 现在的"假"在哪

- 计划 / 角色 / 项目全部是内存里的种子数据，**重启即丢**。
- 演示用的今日计划按"当前时刻"临时铺开（免得一打开全是过期），这部分在 M1 接真数据时删掉。
- 截图里那份等级色（L1 灰 / L2 蓝 / L3 橙）只是视觉分级，没有行为差异。
